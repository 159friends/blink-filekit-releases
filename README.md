# Blink File Kit

Mac, Windows, Linux용 Blink File Kit 설치 파일과 업데이트를 제공합니다.

[최신 설치 파일 받기](https://github.com/159friends/blink-filekit-releases/releases/latest)

- Mac Apple Silicon: `mac-arm64.dmg`
- Windows 64비트: `win-x64-setup.exe` — 일반 설치에 권장
- Windows 무설치: `win-x64-portable.exe`
- Linux 64비트: `linux-x86_64.AppImage`

설치 후 관리자에게 개인적으로 받은 인증 코드를 입력하세요. 허용된 기기 수 안에서 사용할 수 있습니다. 관리자 키는 사용자 인증 코드와 별개입니다.

0.0.90부터 앱 환경 설정에서 새 버전을 확인할 수 있습니다. 다운로드 완료 후 설치 또는 파일 교체 안내를 따라주세요. 0.0.91부터 Mac 앱과 DMG에는 Developer ID 서명과 Apple 공증을 적용합니다. Mac은 DMG에서 앱을 응용 프로그램 폴더로 옮겨 설치하세요. 인터넷에서 받은 앱을 열겠느냐는 정상 확인 화면이 나올 수 있습니다. Windows 실행 파일은 코드 서명하지 않아 Windows 확인 화면이 나올 수 있습니다.

원본 파일은 보존하며 변환·정제 결과는 사본으로 만듭니다. 유튜브 다운로드 도구는 앱과 별도로 업데이트되지만 서비스 변경이나 접속 제한으로 일시적으로 동작하지 않을 수 있습니다.
